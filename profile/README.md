## Governing Autonomous Agents — three open instruments (MIT)

Most agent failures aren't model failures; they're governance failures. We codified how our
own operation stays accountable, and published all three instruments for anyone to adopt —
they're disciplines, not dependencies:

| Instrument | Governs | The core idea |
|---|---|---|
| **[Objective Contracts](https://github.com/RAYFINITE-LLC/objective-contracts)** | one bounded task | Five parts before delegation: intent · a machine-verifiable done condition · an independent finish line · a budget · a scope boundary. The agent that builds never grades its own work. |
| **[Standing Orders](https://github.com/RAYFINITE-LLC/standing-orders)** | a recurring autonomous job | Declared like the military kind — in force until countermanded: classification axes, mandatory stop conditions, a fail-closed go-live gate, a kill switch. |
| **[Agent Charters](https://github.com/RAYFINITE-LLC/agent-charters)** | a standing agent | Five questions answered before it ever runs: *On whose behalf does it act? What may it touch? What does it cost? What trace does it leave? How does it stop?* |

📖 The full story: **[Governing Autonomous Agents](https://rayfinite.com/blog/governing-autonomous-agents)**
